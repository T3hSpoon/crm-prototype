**As a** sales rep managing deals in the pipeline, **I want to** open a deal's full details and edit its core fields without leaving the board, **so that** I can keep each deal's information accurate at a glance.

(This phase-level user story is derived from ROADMAP.md's Phase 2 Goal + Success Criteria to satisfy MVP_MODE framing — the ROADMAP Goal line itself is not yet written in strict "As a/I want to/so that" form. Nothing here adds capability beyond what ROADMAP.md and 02-CONTEXT.md already specify; if the phrasing doesn't sit right, run `/gsd-mvp-phase 2` to rewrite the ROADMAP Goal line properly before executing.)

This plan delivers the "view deal details + edit core fields" vertical slice — DEAL-02 (inline pipeline-table editing) and DEAL-03 (the side drawer) — leaving line items and value rollup to the dependent 02-02 plan.

Purpose: this is the first user-visible capability of Phase 2 — clicking a deal now opens a real, working detail view, and a handful of fields become editable in place, both wired end-to-end through the existing repository seam.
Output: a user can click any deal row to open its detail drawer (showing its full identity: name, company, current stage, value, owner, close date), edit name/value/owner/closeDate either inline in the drawer or inline in the pipeline table, and see every edit committed immediately without leaving the board.
</objective>
