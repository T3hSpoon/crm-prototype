<objective>
**As a** sales rep managing deals in the pipeline, **I want to** build up a deal's value from its line items and only override that total when I genuinely need to, **so that** the deal's total value stays trustworthy and I can always see when and why it no longer matches the sum of its parts.

(This phase-level user story is derived from ROADMAP.md's Phase 2 Goal + Success Criteria to satisfy MVP_MODE framing — see 02-01-PLAN.md's objective for the same note on the ROADMAP Goal line's format.)

This plan delivers the "line items + value rollup" vertical slice — DEAL-04 (add/edit/remove line items) and DEAL-05 (computed-until-touched value with manual override) — extending the drawer built in 02-01-PLAN.md.

Purpose: completes Phase 2's remaining two requirements, turning the drawer from "core-field editor" into the full deal-composition surface the ROADMAP goal describes.
Output: a user can add, edit, and remove line items on any deal from its drawer, see the deal's value auto-track the line-item sum until they manually type a different number, and explicitly reset back to the computed sum via a clearly visible affordance whenever the two diverge.
</objective>
