<objective>
Extend the Add Deal wizard's existing step 2 (Phase 3, DEAL-06) with three new field groups captured on every new deal at creation: Customer Type (required Select, default "Similar"), Confidence Level (required Select, default "Open to RFP Bids"), and four financial metrics — ARPU, MRR, ARR, Lifetime Contract Value (all optional; ARR and Lifetime Contract Value live auto-derive from MRR/Contract Term unless manually edited).

Customer Type and the financial metrics capture data the CRM needs at the point of deal creation rather than retrofitting it later. This task covers only the `Deal`/`NewDealInput` type extension, schema, wizard UI, mock repository, and seed data.

Output: Add Deal wizard step 2 renders all 8 fields (the existing 5 plus these 3 new groups); every newly created and seeded deal carries all 6 new fields; ARR/Lifetime Contract Value live-track MRR/Contract Term until directly edited.
</objective>
