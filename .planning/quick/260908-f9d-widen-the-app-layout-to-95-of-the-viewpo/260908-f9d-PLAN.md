<objective>
Widen the app's primary layout container to ~95% of the viewport width (up from a fixed max-w-5xl / 64rem cap), and replace the deal-detail drawer's line-items UI with an inline expandable table row: a chevron toggle per deal row reveals `LineItemsTable` directly beneath that row. The drawer (`DealDetailDrawer.tsx`) is removed entirely — row click no longer opens anything; only the dedicated chevron expands/collapses line items. This is a user-confirmed design decision (resolved via AskUserQuestion prior to planning) — do not reintroduce the drawer alongside the chevron.

Purpose: The fixed-width board wastes screen space on modern displays, and a side-drawer for line items hides the deal's row context while editing. An inline expandable row keeps the deal and its line items visible together and uses the full pipeline-table width already widened by this task.
Output: Wider PipelineBoard layout; DealTable rows are chevron-expandable to an inline LineItemsTable sub-row (including the "Reset to sum" affordance); DealDetailDrawer.tsx and its now-orphaned Sheet primitive removed.
</objective>
