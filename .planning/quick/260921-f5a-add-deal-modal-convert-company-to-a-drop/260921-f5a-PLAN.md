<objective>
Convert the Add Deal wizard's step-1 Company field from a free-text Input to a Select sourced from a new hand-written mock accounts directory, and add three cascading Selects (Prime Group -> Address -> Contact) right after it, so a new deal's account context is picked from a closed, realistic dataset instead of typed freehand.

Purpose: today `company` is arbitrary free text with no relationship to any structured account/location/contact data. This introduces that structure (`Account` -> `AccountPrimeGroup` -> `AccountContact`) as a small, hand-written, swap-ready mock dataset — the same "repository/adapter" pattern this project already uses for deals — so the Add Deal form captures which physical location and point of contact a new deal is tied to.

Output: `src/data/mock/accounts-directory.ts` (new: `Account`/`AccountPrimeGroup`/`AccountContact` types, `ACCOUNTS_DIRECTORY`, `getCompanyNames()`, `getPrimeGroupsForCompany()`) + its structural-invariant test file; `Deal`/`NewDealInput` widened with `primeGroup`/`address`/`contact`; `add-deal-schema.ts`'s step-1 schema requires all three; `AddDealDialog.tsx`'s step 1 gets the Company Select conversion plus the 3 new cascading Selects; `MockDealsRepository.create()` passes the 3 fields through untransformed.
</objective>
