<objective>
Remove the manual "Value" input field from step 1 of the Add Deal wizard.
Value is already established (Phase 2, DEAL-05) as a computed sum of a
deal's line items; a brand-new deal has zero line items at creation, so the
field's existing default of `0` is already the correct computed value — no
input UI is needed for it.

Purpose: Stop asking the user to manually enter a number that the app itself
overrides/derives once line items are added, eliminating a redundant and
confusing input.

Output: `AddDealDialog.tsx` step 1 no longer renders a Value input/label;
`value` still flows through the schema, type, and `DEFAULT_VALUES` as a
non-interactive `0`, and step 1 validation/`Next` no longer references it.
</objective>
