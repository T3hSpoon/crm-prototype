<objective>
**As a** sales rep adding a new prospect or deal, **I want to** capture its deal-terms/contract fields (Prorata, Grace Period, Contract Term, Frequency, Currency) through a second step of the Add Deal wizard, **so that** every deal created from now on already carries the data a future contract/quote-template feature will need, regardless of which pipeline stage it starts in.

(This phase-level user story is derived from ROADMAP.md's Phase 3 Goal + Success Criteria to satisfy MVP_MODE framing, following the same convention 02-01-PLAN.md/02-02-PLAN.md used for their objective blocks.)

This plan delivers DEAL-06's entire scope as one vertical slice: converting the existing single-step `AddDealDialog` into a 2-step wizard (Task 1, tracer — the full working feature end to end), then hardening it to exactly match 03-UI-SPEC.md's copywriting/validation contract (Task 2).

Purpose: closes the only requirement in Phase 3, and is a load-bearing precursor to Phase 3.1 (Lost & Won Tracking) and Phase 4 (Forecast), both of which assume every deal already carries consistent contract-terms data.
Output: every new deal, created from any pipeline stage, carries all 5 deal-terms fields; step-1 (existing) and step-2 (new) values survive Back/Next navigation; Cancel discards everything from either step.
</objective>
