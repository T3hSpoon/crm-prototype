# Phase 01 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| npm registry -> local node_modules | Every `npm install`/`npx shadcn` command (01-01) pulls third-party code onto the dev machine | Package source code |
| Repository/store layer -> external network | No network call should ever originate from `src/data/` or `src/features/pipeline/store/` this phase — everything resolves against the in-memory array | N/A (boundary must stay unused this phase) |
| Browser (user-typed form input) -> in-memory Zustand store | The Add Deal form is this phase's only genuinely untrusted-input trust boundary | Free-text/number form input (name, company, value, owner, close date) |

| T-01-07 | Spoofing / Elevation of Privilege | entire app — no authentication exists | low | accept | Single-user, no backend, no session this phase — explicitly out of scope for this milestone per PROJECT.md; nothing to spoof or escalate without an identity system | closed |
