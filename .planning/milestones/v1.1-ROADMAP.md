## Phase Details

### Phase 5: Confidence-Based Forecast Breakdown

**Goal**: Users can edit a deal's confidence level directly from the pipeline table, and analyze the entire pipeline (open, won, and lost) as a confidence-grouped financial breakdown on the Forecast page
**Depends on**: Phase 4
**Requirements**: DEAL-07, FCST-03, FCST-04
**Success Criteria** (what must be TRUE):

  1. User can click a deal's Confidence cell in the pipeline table and select a new value (100/80/50/Open-to-RFP) using the same inline click-to-edit pattern already used for owner/value/closeDate, with the change persisting to the deal
  2. The Forecast page shows a new table listing every deal in the pipeline — open, won, and lost — grouped under its confidence level, with per-deal columns for Account Name, Model, Services, Quantity, ARPU, MRR, ARR, Lifetime Contract Value, and Contract Length
  3. Each confidence group in the new table displays a subtotal row for Quantity/MRR/ARR/Lifetime Contract Value, and the table ends with a grand-total row summarizing those same columns across every deal
  4. Changing a deal's confidence level in the pipeline table moves it into the corresponding confidence group the next time the Forecast page's breakdown table is viewed

**Plans**: 1/1 plans executed
